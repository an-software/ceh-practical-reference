# GDB

Category: Forensics. Purpose: Debugger for controlled lab execution and state inspection.

## Basic workflow

1. Use an isolated authorized sample/environment.
2. Load symbols/architecture appropriately.
3. Set a narrow breakpoint and document observed state.

## Troubleshooting

Debugging executes code and can change state; static analysis is safer for initial unknown-file triage.
