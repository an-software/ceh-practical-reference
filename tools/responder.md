# Responder

Category: Passwords. Purpose: Lab assessment of name-resolution/authentication behavior and related captures.

## Basic workflow

1. Review the active modules and exact network scope.
2. Prefer a supplied authentication capture for basic analysis.
3. Distinguish the captured challenge-response format before offline recovery.

## Troubleshooting

Active poisoning can affect other hosts; a captured NetNTLMv2 response is not a raw NTLM hash.
