# CrypTool

Category: Cryptography. Purpose: GUI learning environment for specified cryptographic exercises.

## Basic workflow

1. Select the exact algorithm/mode.
2. Enter lab-provided key encoding/IV/padding.
3. Check the decoded output against the task.

## Troubleshooting

3DES is symmetric; scenario-specific repeated key bytes from old notes are not universal defaults.
