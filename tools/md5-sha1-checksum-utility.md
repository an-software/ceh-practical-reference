# MD5 & SHA-1 Checksum Utility

Category: Cryptography. Purpose: Historical GUI checksum tool named in the imports.

## Basic workflow

1. Select the actual lab file.
2. Choose the exact requested digest.
3. Compare against a trusted same-algorithm value.

## Troubleshooting

MD5/SHA1 are legacy choices; equal digests do not authenticate an origin.
