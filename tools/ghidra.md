# Ghidra

Category: Forensics. Purpose: Static disassembly/decompilation and executable structure review.

## Basic workflow

1. Import a copied lab executable.
2. Confirm architecture/load addresses and analyze.
3. Inspect entry point and relevant references/functions.

## Troubleshooting

Decompiled output is an interpretation; unknown code should not be executed on the normal workstation.
