# RainbowCrack

Category: Passwords. Purpose: Recover supported unsalted hashes with matching rainbow tables.

## Basic workflow

1. Confirm algorithm and table parameters.
2. Load supplied compatible tables.
3. Verify returned candidates locally.

## Troubleshooting

Unique salts undermine table reuse; tables must match algorithm, charset and length assumptions.
