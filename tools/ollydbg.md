# OllyDbg

Category: Forensics. Purpose: Historical Windows debugger named in source notes.

## Basic workflow

1. Confirm architecture/version compatibility.
2. Use an isolated disposable lab.
3. Inspect a controlled breakpoint and record state.

## Troubleshooting

A 32-bit-era debugger is not a universal choice for modern 64-bit samples.
