# sandfly-entropyscan

Category: Forensics. Purpose: Entropy-oriented Linux file/process triage referenced by the root guide.

## Basic workflow

1. Review the installed scanner's local help.
2. Compare equivalent file/range measurements.
3. Hash and inspect the candidate flagged by the lab.

## Troubleshooting

High entropy can mean compression/encryption, not necessarily malware; identify the actual file before hashing.
