# Stegseek

Category: Forensics. Purpose: Recovery/analysis for supported [Steghide](steghide.md) data.

## Basic workflow

1. Verify the carrier and supported [Steghide](steghide.md) format.
2. Use a small lab candidate list where permitted.
3. Validate the extracted file separately.

## Troubleshooting

It does not solve arbitrary image steganography or incompatible formats.
