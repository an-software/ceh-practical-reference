# Burp Suite

Category: Web testing. Purpose: Intercept and compare lab web requests and session behavior.

## Basic workflow

1. Configure an isolated browser/profile and target scope.
2. Capture a baseline and use Repeater for one change at a time.
3. Validate findings and export redacted evidence.

## Troubleshooting

Intruder attack types can multiply requests; 302 is not proof of a successful login.
