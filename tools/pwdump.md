# Pwdump / Pwdump7

Category: Passwords. Purpose: Historical Windows password-hash extraction utilities.

## Basic workflow

1. Identify the specific binary and required privileges.
2. Prefer lab-provided synthetic output for recovery practice.
3. Protect any authorized output as credential material.

## Troubleshooting

Different similarly named utilities have different behavior; extraction is privileged and not mere user enumeration.
