# Android Studio emulator

Category: Mobile and cloud. Purpose: Create a controlled Android application/device test environment.

## Basic workflow

1. Use a disposable lab virtual device.
2. Record OS/app versions.
3. Inspect permissions and API behavior with synthetic data.

## Troubleshooting

An emulator may not reproduce device-specific behavior or hardware-backed features.
