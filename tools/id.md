# id

Category: Privilege escalation. Purpose: Report Unix identity and group membership.

## Basic workflow

1. Run in the actual lab session.
2. Record UID/GIDs.
3. Compare identity before/after authorized validation.

## Example

Run manually in the appropriate authorized lab environment; replace sample names/addresses and check installed-version help.

```bash
id
```


## Troubleshooting

A remote shell and the local terminal can be different users/hosts.
