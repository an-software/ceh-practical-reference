# VirusTotal

Category: Forensics. Purpose: Online multi-engine/reputation service.

## Basic workflow

1. Prefer an allowed digest lookup before any file submission.
2. Check the report's timestamps/context.
3. Corroborate detections with independent evidence.

## Troubleshooting

Uploading may disclose data; engine counts alone do not prove a file is malicious.
