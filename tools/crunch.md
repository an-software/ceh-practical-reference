# Crunch

Category: Passwords. Purpose: Generate candidate strings from specified lengths/character sets.

## Basic workflow

1. Estimate the candidate space first.
2. Choose a small synthetic pattern.
3. Write results only if disk usage is reasonable.

## Example

Run manually in the appropriate authorized lab environment; replace sample names/addresses and check installed-version help.

```bash
crunch -h
```


## Troubleshooting

Combinatorial output grows quickly; a generic huge list can exhaust disk and time.
