# WinDbg

Category: Forensics. Purpose: Windows dump analysis and controlled debugging.

## Basic workflow

1. Identify dump/live-debug target.
2. Configure appropriate symbols.
3. Use focused inspection and record context.

## Troubleshooting

Wrong symbols/architecture impair conclusions; live debugging can alter execution.
