# OWASP WSTG

Category: Reference utilities. Purpose: Web Security Testing Guide reference, not an executable.

## Basic workflow

1. Choose a test area matching the application.
2. Record preconditions and expected behavior.
3. Link validated evidence to the relevant test.

## Troubleshooting

A checklist entry does not imply the application is vulnerable.
