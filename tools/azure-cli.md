# Azure CLI (az)

Category: Mobile and cloud. Purpose: Query/manage authorized Azure resources.

## Basic workflow

1. Confirm tenant/subscription identity.
2. Inspect scoped resources and permissions.
3. Validate a synthetic allowed read.

## Troubleshooting

Account context matters; credential/token files and exported secrets do not belong in Git.
