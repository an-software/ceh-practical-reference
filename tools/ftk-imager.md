# FTK Imager

Category: Forensics. Purpose: Acquire/view disk and file evidence in a forensic workflow.

## Basic workflow

1. Select the correct authorized source and destination.
2. Use the appropriate imaging/verification workflow.
3. Record hashes, acquisition settings and source handling.

## Troubleshooting

Do not write an image onto its source medium; a live acquisition may alter state.
