# Dcomcnfg / Component Services

Category: Enumeration. Purpose: Inspect Windows DCOM configuration and permissions.

## Basic workflow

1. Open the relevant component properties.
2. Review launch/access identities and permissions.
3. Document configuration without changing it.

## Troubleshooting

The source spelling Dcomcnf is a typo; changing settings may disrupt dependent applications.
