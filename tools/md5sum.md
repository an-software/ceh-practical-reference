# md5sum

Category: Cryptography. Purpose: Calculate MD5 for an explicit legacy lab task.

## Basic workflow

1. Select the actual input bytes.
2. Calculate the digest.
3. Compare against the same-algorithm trusted reference.

## Example

Run manually in the appropriate authorized lab environment; replace sample names/addresses and check installed-version help.

```bash
md5sum lab-file.txt
```


## Troubleshooting

MD5 collision resistance is insufficient for modern authenticity/security designs.
