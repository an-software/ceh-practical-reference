# winPEAS

Category: Privilege escalation. Purpose: Windows local privilege-enumeration member of PEASS.

## Basic workflow

1. Choose an appropriate reviewed build.
2. Record token/identity and visible configuration.
3. Validate the exact service/task/ACL relationship.

## Troubleshooting

Restricted tokens limit visibility; a possible DLL search issue needs path and execution-context evidence.
