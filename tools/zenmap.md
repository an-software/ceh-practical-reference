# Zenmap

Category: Discovery. Purpose: GUI for [Nmap](nmap.md) scans and result review.

## Basic workflow

1. Choose the authorized target.
2. Inspect the generated [Nmap](nmap.md) command before starting.
3. Save and compare results with the same scope.

## Troubleshooting

A GUI profile can run broader scripts or probes than expected; the underlying [Nmap](nmap.md) permissions still apply.
