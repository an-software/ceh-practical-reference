# NoSQLMap

Category: Historical SQL tools. Purpose: Assessment tooling for some NoSQL configurations/injection scenarios.

## Basic workflow

1. Identify the actual backend and input path.
2. Review the supported version and behavior.
3. Validate only a scoped synthetic scenario.

## Troubleshooting

NoSQL is not one protocol; [SQLmap](sqlmap.md)/SQL syntax cannot simply be assumed interchangeable.
