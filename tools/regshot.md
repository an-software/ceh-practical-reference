# Regshot

Category: Forensics. Purpose: Compare Windows registry snapshots around a controlled change.

## Basic workflow

1. Take a baseline in a disposable lab.
2. Perform the single authorized test action.
3. Compare the second snapshot and inspect differences.

## Troubleshooting

Background system changes can appear in the diff; correlation alone is not causation.
