# nslookup

Category: Discovery. Purpose: Basic DNS query troubleshooting.

## Basic workflow

1. Check the resolver used.
2. Query the lab hostname.
3. Compare with another authorized resolver if necessary.

## Example

Run manually in the appropriate authorized lab environment; replace sample names/addresses and check installed-version help.

```bash
nslookup lab.example
```


## Troubleshooting

Local hosts-file behavior and DNS answers are different sources of resolution.
