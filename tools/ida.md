# IDA

Category: Forensics. Purpose: Disassembly and optional debugging of executable code.

## Basic workflow

1. Import a copied lab binary.
2. Confirm processor/image layout.
3. Inspect entry point and cross-references.

## Troubleshooting

Static navigation does not prove a path executed; debugger use requires an isolated environment.
