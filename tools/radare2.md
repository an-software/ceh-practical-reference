# radare2

Category: Forensics. Purpose: Binary inspection, disassembly and reverse-engineering framework.

## Basic workflow

1. Open the working copy using a non-debugging inspection workflow.
2. Confirm architecture and entry metadata.
3. Review relevant functions/references.

## Troubleshooting

Analysis and debugging modes differ; avoid assuming the displayed virtual address is a file offset.
