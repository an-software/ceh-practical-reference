# Browser developer tools

Category: Web testing. Purpose: Inspect lab requests, response headers, cookies and storage.

## Basic workflow

1. Use an isolated profile.
2. Capture a known-good request.
3. Compare one change and note authenticated state.

## Troubleshooting

Stored sessions/tokens are sensitive; cached content and redirects can confuse comparisons.
