# GTFOBins

Category: Privilege escalation. Purpose: Reference catalog of Unix binary behaviors under specific permissions.

## Basic workflow

1. Start with actual [sudo](sudo.md)/SUID/capability evidence.
2. Read the matching binary/context entry.
3. Validate only the scoped behavior and record the fix.

## Troubleshooting

A listed binary's mere presence does not establish privilege escalation.
