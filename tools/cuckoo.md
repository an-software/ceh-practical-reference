# Cuckoo Sandbox

Category: Forensics. Purpose: Automated dynamic-analysis platform referenced by the source list.

## Basic workflow

1. Use an isolated configured analysis environment.
2. Submit only a permitted lab sample.
3. Correlate behavior reports with static/packet evidence.

## Troubleshooting

Execution changes environment state; containment and collection coverage need validation.
