# Google Cloud CLI (gcloud)

Category: Mobile and cloud. Purpose: Query/manage authorized Google Cloud resources.

## Basic workflow

1. Confirm active identity/project.
2. Inspect permitted resource and IAM views.
3. Record configuration plus observed access.

## Troubleshooting

A public endpoint is not the same as publicly readable data; do not assume commands are read-only.
