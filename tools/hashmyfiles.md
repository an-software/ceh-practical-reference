# HashMyFiles

Category: Cryptography. Purpose: GUI hash calculation for multiple files.

## Basic workflow

1. Select copied input files and the requested algorithm.
2. Calculate and compare digests.
3. Export only the required verification evidence.

## Troubleshooting

A filename match is not a content match; avoid using legacy digests as authenticity proof.
