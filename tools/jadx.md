# JADX

Category: Mobile and cloud. Purpose: Inspect/decompile Android application code.

## Basic workflow

1. Open a copied permitted APK.
2. Review manifest/resources and relevant code paths.
3. Corroborate findings with controlled behavior.

## Troubleshooting

Decompiled code may be incomplete/obfuscated; embedded text is not proof a credential is live.
