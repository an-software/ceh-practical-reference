# WinSCP

Category: Mobile and cloud. Purpose: GUI transfer using supported remote file protocols.

## Basic workflow

1. Select the correct protocol/port.
2. Verify the server identity and log in with lab credentials.
3. Transfer only the required file and compare its hash.

## Troubleshooting

FTP and SFTP are different protocols; a valid account may still lack file permissions.
