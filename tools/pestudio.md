# PEStudio

Category: Forensics. Purpose: Static Windows executable triage.

## Basic workflow

1. Open an evidence copy.
2. Review headers/imports/indicators.
3. Corroborate suspicious properties with other analysis.

## Troubleshooting

Indicators and optional reputation results require interpretation; do not upload sensitive artifacts casually.
