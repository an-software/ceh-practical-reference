# Remote Desktop / RDP client

Category: Mobile and cloud. Purpose: Interactive access to an authorized Windows lab session.

## Basic workflow

1. Verify the target identity.
2. Use supplied credentials and authorized client.
3. Record the session's user/host context.

## Troubleshooting

An open 3389 port does not prove credentials work or that the user is an administrator.
