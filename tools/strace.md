# strace

Category: Forensics. Purpose: Observe Linux system calls of a controlled process.

## Basic workflow

1. Choose a known lab executable/process.
2. Limit the trace scope.
3. Correlate calls/errors with observed behavior.

## Troubleshooting

Tracing can alter timing and exposes sensitive arguments; do not execute unknown code merely to trace it.
