# Hash-Identifier

Category: Passwords. Purpose: Interactive suggestions for possible hash algorithms.

## Basic workflow

1. Supply a permitted sample.
2. Record candidate formats.
3. Confirm using application context before cracking.

## Troubleshooting

A digest's appearance does not reveal whether a particular salted/application format was used.
