# Process Monitor / ProcMon

Category: Forensics. Purpose: Windows file, registry and process/thread activity monitoring.

## Basic workflow

1. Create a focused process/path filter.
2. Collect a short authorized lab interval.
3. Correlate events with the action and save the trace.

## Troubleshooting

Noisy capture and dropped events limit conclusions; activity does not itself establish malicious intent.
