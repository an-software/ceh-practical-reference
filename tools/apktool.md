# Apktool

Category: Mobile and cloud. Purpose: Decode Android application resources/manifest for inspection.

## Basic workflow

1. Use a copied lab package.
2. Inspect decoded manifest/resources.
3. Record only the relevant configuration evidence.

## Troubleshooting

Rebuilding/re-signing changes the package and is separate from reading it; formats vary by app.
