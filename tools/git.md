# Git

Category: Reference utilities. Purpose: Local note versioning and tracked-file search.

## Basic workflow

1. Review changed paths.
2. Stage only intended reference files.
3. Commit locally after checks.

## Example

Run manually in the appropriate authorized lab environment; replace sample names/addresses and check installed-version help.

```bash
git status --short
```


## Troubleshooting

Ignored directories are not a secret scanner and already-tracked files remain tracked; no push is required.
