# AWS CLI

Category: Mobile and cloud. Purpose: Query/manage authorized AWS resources.

## Basic workflow

1. Confirm identity, account and region.
2. Use read-only inventory/policy views.
3. Record effective access and minimal evidence.

## Troubleshooting

Commands can mutate resources; wrong account/region and insufficient permissions can look like absent resources.
