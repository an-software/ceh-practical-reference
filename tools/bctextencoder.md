# BCTextEncoder

Category: Cryptography. Purpose: Text encryption/decryption GUI referenced by the cheatsheets.

## Basic workflow

1. Confirm the exact encoded container.
2. Use the supplied lab key/password.
3. Save decrypted test output outside Git.

## Troubleshooting

Do not treat arbitrary Base64 or [OpenStego](openstego.md) output as a compatible BCTextEncoder container.
