# YARA

Category: Forensics. Purpose: Pattern-based file classification.

## Basic workflow

1. Review a trusted lab rule and scope.
2. Scan copies with the intended rule set.
3. Inspect the exact matched strings/condition.

## Troubleshooting

A rule hit is not a malware verdict; noisy rules create false positives.
