# RpcDump

Category: Enumeration. Purpose: Inspect RPC endpoint registration using the particular installed implementation.

## Basic workflow

1. Identify whether the tool is the Windows or another implementation.
2. Review local syntax and scoped endpoint.
3. Correlate exposed interfaces with service identity.

## Troubleshooting

Similarly named tools differ; an endpoint listing is not proof a method is exploitable.
